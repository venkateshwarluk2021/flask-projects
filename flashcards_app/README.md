# Flashcards App 🧠

A simple interactive Flashcards web app built with **Flask**, **Bootstrap**, and **JavaScript**. Users can flip cards, view questions/answers, mark them as correct/incorrect, and view their final score at the end.

## 🚀 Features

- Interactive flip-card animation using CSS & JavaScript
- Multiple flashcard questions with session-based tracking
- Score summary with correct and incorrect answers
- Clean and responsive UI using Bootstrap 5
