# Flask Practice

This repository contains my practice projects and experiments using **Flask**, a lightweight Python web framework.

## 📚 About This Repository

This repo is for learning and testing Flask concepts, including:

- Routing and views
- Templates (Jinja2)
- Forms and request handling
- Static files (CSS, JS, images)
- Database connections (future)
- Testing with pytest (future)
- Deployment experiments (future)

---

## 🛠 Tech Stack

- Python 3.x
- Flask
- HTML / CSS (templates)
- [Optional] Bootstrap (if you add styling)
- [Optional] SQLite or other DBs for future practice
