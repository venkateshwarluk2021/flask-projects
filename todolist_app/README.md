# 📝 Flask ToDo List App

This is a simple Flask-based ToDo List web application where users can add, view, update, and delete their tasks. The application uses **SQLite** as the database and **Bootstrap** for styling, making it lightweight and responsive.

## 🚀 Features

- Add new tasks with a title and description
- View all pending tasks
- Edit existing tasks
- Delete tasks
- Flash messages for success and error feedback
- Clean Bootstrap UI

## 🛠️ Tech Stack

- **Backend**: Flask (Python)
- **Frontend**: HTML, Bootstrap
- **Database**: SQLite
- **Templating**: Jinja2

## 🧑‍💻 Getting Started

### Prerequisites

- Python 3.x installed
- Flask installed (`pip install flask`)

### Run Locally

```bash
# Clone the repo
git clone https://github.com/venkateshwarluk2021/flask-practice.git
cd flask-practice/todolist_app

# Run the app
python flask_todo_app.py
- Then visit http://127.0.0.1:5000 in your browser.

## Testing
- Manual testing can be done by adding, editing, and deleting tasks.
- Flash messages indicate success or failure for each operation
