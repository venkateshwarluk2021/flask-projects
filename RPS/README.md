## Overview

Users can play Rock-Paper-Scissors against the computer. The user selects Rock, Paper, or Scissors; the app randomly generates a choice for the computer; then shows the result (win / lose / draw).

---

## Features

- Choice input: Rock, Paper, or Scissors  
- Computer's choice decided randomly  
- Display of result: whether user won, lost or tied  
- Basic front-end using Flask templating  
- Simple and intuitive UI  

---

## Technologies Used

- Python 3  
- Flask  
- HTML / CSS / (optional JS)  
- Random module for game logic

## Installation

1. **Clone the repository**

   - ```bash
  -  git clone https://github.com/venkateshwarluk2021/flask-practice.git
  -  cd flask-practice/RPS
2. **Create and activate a virtual environment**
 -  python3 -m venv venv
- source venv/bin/activate    # on Linux / macOS
# or on Windows
- venv\Scripts\activate

3. **Install dependencies**
  - If there is a requirements.txt: pip install -r requirements.txt
- Otherwise: pip install flask

4. **Usage**
 -  Make sure your virtual environment is activated.
- Run the Flask app. For example: flask run
- Or, if you have a specific entry file (e.g. app.py or main.py): python app.py
- Open your browser at http://127.0.0.1:5000 (or whichever host/port is configured).
- Select Rock, Paper, or Scissors from the UI.
- See the computer’s choice and the result.
