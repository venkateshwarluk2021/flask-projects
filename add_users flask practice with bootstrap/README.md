# Flask User Form Practice with Bootstrap

This project is a basic Flask web application demonstrating how to create a user form with Bootstrap styling. It is part of my hands-on practice to learn Flask, HTML, and Bootstrap integration.

## 🚀 Features

- Simple user form (Name, Email)
- Bootstrap styling for responsive layout
- Displays submitted data on a separate page
- Basic Flask routing and template rendering

## 🛠 Tech Stack

- Python 3
- Flask
- HTML + Jinja2 Templates
- Bootstrap 5
